# Forma extensions

This repository is the update channel for Forma Studio.

Forma is a small Windows core. Cloud features — Amazon Web Services, Azure, Google Cloud, DigitalOcean, Docker, Kubernetes and starters — live here as JSON packs. Connect GitHub inside Forma, then **Publish extensions**. Tomorrow’s AWS buttons ship as a pack update, not a new installer.

Each folder has a `forma-extension.json`. Packs may only run programs already on PATH. They cannot run downloaded scripts.

`catalog.json` is the index Forma downloads.
